# The Legacy of Goku 4 — Dragon Ball GT DLC

## Play
1. mGBA → `ROM/LegacyOfGoku4_GT_DLC.gba` (16 MB)
2. New Game → reach **Snake Way**
3. Talk to **East Kai** (extra NPC — King Kai still there)
4. You enter **SSJ4** (red fur, separate from SS3)
5. Skills: IT, Kamehameha, Super Saiyan (+ SS4 path)
6. SS3 remains fully original

## Form ladder
**SS4 (form 1) > SS3 (form 5, original) > SS1 (form 3) > Base (form 0)**
