# Vertical Slice 0 — Otro Mundo / Snake Way

## Qué existe

Se añadió un proyecto Godot 4 mínimo y una escena ejecutable sin assets externos. Es un prototipo de sistemas, no una demo final de arte:

- Ventana lógica 240×160 con escalado 4×.
- Movimiento de Goku provisional dentro de Snake Way.
- Carga de Ki, ataque, enemigo de entrenamiento, HP/Ki y HUD.
- NPC King Kai con misión simple de derrotar al enemigo.
- Guardado y carga JSON local versionados.

## Controles

| Acción | Tecla |
|---|---|
| Mover | WASD o flechas |
| Atacar | Espacio |
| Cargar Ki | R |
| Hablar/interactuar | E |
| Guardar | F5 |
| Cargar | F9 |

## Cómo ejecutar

1. Instalar Godot 4.3 o superior.
2. Importar la carpeta `standalone_game/` en Godot.
3. Ejecutar el proyecto (`F6` o `F5` dentro de Godot).
4. Hablar con King Kai, derrotar al enemigo y probar guardar/cargar.
